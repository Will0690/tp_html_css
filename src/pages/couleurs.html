Mini projet (carte UI)

Ce modèle est une liste de composants de type « carte » avec pieds de page optionnels. Une carte contient un titre, une image, une description ou autre contenu, ainsi qu'une mention de source ou un pied de page. Les cartes sont généralement affichées au sein d'un groupe ou d'une collection.
